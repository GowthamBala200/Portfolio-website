GOWTHAM B - Portfolio website

Files
  index.html        Page structure and content
  css/style.css     All styling, 3D environment and scroll animations
  js/main.js        3D project viewer (tap a project to open it)
  assets/photo.jpg  Profile photo

Run locally
  Open index.html in any modern browser. No build step or install is needed.

Publish on GitHub Pages
  1. Create a public repository named GowthamBala200.github.io
  2. Upload everything in this folder (keep the folder structure)
  3. Settings > Pages > Deploy from branch: main, folder: / (root)
  4. Your site will be live at https://gowthambala200.github.io

Edit your details
  Text, links and email are in index.html. Colors are the variables at the top of css/style.css.
  To change the photo, replace assets/photo.jpg (keep the name).
